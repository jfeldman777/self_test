# Игра: Расставь элементы правильно

Игра на drag-and-drop, где нужно расставить элементы таблицы в правильном порядке.

## Структура файлов

- `index.html` - основная страница игры
- `style.css` - стили
- `script.js` - логика игры
- `images/` - папка для изображений таблиц (создайте эту папку)

## Как добавить свои уровни

1. Загрузите изображения таблиц в папку `images/` (например, `level1.png`, `level2.png` и т.д.)

2. Откройте `script.js` и добавьте уровни в массив `gameLevels`:

```javascript
const gameLevels = [
  {
    level: 1,
    image: 'images/level1.png', // путь к изображению
    rows: 3,  // количество строк
    cols: 3,  // количество столбцов
    elements: [
      { id: 1, content: '1' },
      { id: 2, content: '2' },
      // ... и т.д.
    ]
  },
  // Добавьте больше уровней
];
```

## Как использовать изображения элементов

Если у вас есть отдельные изображения для каждого элемента, используйте:

```javascript
elements: [
  { id: 1, image: 'images/element1.png', content: 'Элемент 1' },
  { id: 2, image: 'images/element2.png', content: 'Элемент 2' },
  // ...
]
```

## Особенности

- Drag-and-drop с визуальной обратной связью
- Элементы меняются местами (swap)
- Подсчет ходов
- Проверка правильности расстановки
- Поддержка нескольких уровней
