Описание системы

Расставь элементы правильно

Игра на drag-and-drop: нужно расставить элементы таблицы в правильном порядке.

  • Нажмите ИГРА — элементы перемешаются.
  • Перетаскивайте ячейки, меняя их местами.
  • Нажмите ГОТОВО — система проверит правильность.

System description

Arrange the elements correctly

A drag-and-drop game: you need to arrange the table elements in the correct order.

  • Press PLAY — the elements will be shuffled.
  • Drag cells to swap them.
  • Press DONE — the system will check correctness.
