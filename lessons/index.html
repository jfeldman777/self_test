Регламент. Общие положения

▼
  1. Курс проходит по понедельникам в зуме с 22 00 по Москве, с 21 00 по Киеву
  2. Все занятия проводятся в Zoom, постоянная ссылка будет разослана участникам по списку
  3. Знакомство и проверка технической готовности состоится в понедельник 29 декабря. Желательно появиться вовремя, уйти можно будет после представления
  4. Домашние задания следует сдавать не позднее чем через сутки после урока Хранителю Домашних Заданий. Там в свободной форме должны быть описаны ваши впечатления, пожелания и вопросы
  5. Занятия желательно не пропускать. Если есть острая необходимость пропустить, следует предупредить Держателя Списка Участников не позднее чем за сутки.
  6. Занятие делится на лекцию (15 минут), вопросы лектору и его ответы (еще 10-15 минут), обсуждение БЕЗ лектора с модератором (по желанию, но не более часа)
